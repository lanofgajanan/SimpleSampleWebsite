07 / FAQ

Questions, answered.

What is NOVA?+

NOVA is a terminal-first AI coding agent. It can understand goals, plan implementation, use your local tools, and leave behind a clear record of its work.

Does NOVA work over SSH?+

Yes. NOVA is designed for headless and remote environments—no display server or GUI application is required.

Can I review changes before they're applied?+

Always. NOVA presents its plan and produces session artifacts including diffs and test output, so you stay in control.

Which languages and frameworks are supported?+

NOVA works with the files and command-line tools in your project, so it is flexible across languages and stacks.

Is my code used for training?+

No. Your code remains yours. NOVA is designed with privacy-conscious development workflows in mind.
