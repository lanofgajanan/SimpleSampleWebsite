# NOVA Landing Page

A responsive, terminal-inspired landing page for NOVA: an agentic AI coding tool designed for terminal-first workflows.

## Tech

- Semantic HTML5
- Vanilla CSS (custom properties, transitions, keyframes, responsive layouts)
- Vanilla JavaScript (mobile nav, scroll reveal, count-up stats, back-to-top control)

## Run locally

Open `index.html` in a browser, or serve the directory with any static-file server.

## Notes

The visual system uses a dark terminal palette, monospace headings, sharp corners, and artifact-style terminal UI. Interactions are intentionally dependency-free and kept straightforward for a live walkthrough.
